# Security policy

## Reporting a vulnerability

Email **security@radiodiodj.org**. Please do not open a public issue for a
vulnerability.

Include what you can of: the affected version, the platform, steps to reproduce,
and what an attacker gains.

## Supported versions

Fixes land in the
[latest release](https://github.com/Arskah/radiodiodj/releases/latest) only.
